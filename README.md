# 5×5 ダンジョン探索

## ゲーム概要

見下ろし型の小さな探索ゲームです。プレイヤーは5×5の部屋を一部屋ずつ移動し、気になる部屋で「探索」します。部屋の中身は探索するまで分かりません。鍵を見つけて出口の部屋へ行けば脱出成功、爆弾を見つけるとゲームオーバーです。

## 遊び方

- WASD / 矢印キーで上下左右に1部屋ずつ移動します。
- 「この部屋を探索」ボタン、またはSpaceで現在の部屋を探索します。
- まだ探索していない部屋は「？」で表示されます。探索した部屋は中身が表示されます。
- 鍵は1個だけ。取得後、出口の部屋で「脱出する」を押すとクリアです。
- 爆弾の部屋を探索すると即ゲームオーバーです。
- 「最初から」で配置を変えずにやり直せます。

## 現在の試作ルール

- 部屋は5×5。開始位置は左下 (1,1)、出口は右上 (5,5)。
- 部屋の中身は開始時に決まっており、画面では探索するまで隠されています。
- 仮配置: 鍵 (3,3)、爆弾 (2,4)、爆弾 (4,2)。それ以外は空です。
- 探索済みの部屋は再探索しても何も起きません。
- 移動回数や制限時間はありません。

## 配置を変える

`Assets/Scripts/DungeonGame.cs` の `RestartGame()` 内にある `PlaceItem(x, y, ItemType.Key/Bomb)` を編集してください。座標は左下を (1,1)、右上を (5,5) とします。出口と開始位置にはアイテムを置かないルールです。

## Asset Store

今回の試作は外部素材なしで動くよう、図形と文字で画面を作ります。見た目を差し替える場合の候補:

- [RPG Worlds Caves](https://assetstore.unity.com/packages/2d/environments/rpg-worlds-caves-167274) — 無料のトップダウン向け32×32ピクセル素材。標準Unity Asset Store EULA。
- [Pixel Art Top Down - Basic](https://assetstore.unity.com/packages/2d/environments/pixel-art-top-down-basic-187605) — Cainos作の無料トップダウン素材。Asset Store表示では32×32、URP対応。標準Unity Asset Store EULA。

素材はこのプロトタイプにはまだ取り込んでいません。必要になったらUnity EditorのAsset Store/My Assetsから取得し、内容とライセンスを確認してから使います。
